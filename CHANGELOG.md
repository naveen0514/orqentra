# Changelog

## 2.0.0

- Replaced the manual workflow dashboard with a prompt-first chat workspace and separate live activity monitor.
- Added asynchronous background workflow execution and pause/resume handling.
- Added portal discovery via a small service registry and optional search.
- Added local reusable applicant profile memory and document vault with RAG-style retrieval.
- Added document upload requests in chat, document reuse and supported file attachment matching.
- Added transient OTP entry that does not persist the code.
- Added automatic high-confidence form filling, conservative application-link discovery, Next/Continue navigation and guarded final submit.
- Added optional local Llama 3/Ollama fallback and macOS launch scripts.
